# Digital Forensics and Incident Response (DFIR) Framework Automation

## Project Overview
An automated framework designed to accelerate artifact acquisition, correlate endpoint telemetry, and execute rapid host containment.

## Repository Structure
- `src/acquisition/`: Memory and disk capture automation scripts
- `src/analysis/`: Telemetry parsing and timeline utilities
- `detections/sigma/`: Curated Sigma detection rules
- `playbooks/`: Host isolation and containment scripts
- `tests/simulation/`: Atomic Red Team attack simulation scripts
- `docs/`: Architecture diagrams and chain-of-custody templates
